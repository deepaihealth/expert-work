面向平台运维（system_admin）——租户的建、配、停三件事。

## 建租户

进「设置 → 租户」（`/settings/tenants`，仅 system_admin 可见），点「创建租户」打开表单：

- **显示名**（必填）、**套餐**（free / pro / enterprise，默认 free）。
- **租户 id**：留空由服务端自动生成 UUID（推荐）；只有从上游系统做幂等对接时才需要自己填一个合法 UUID。
- **首管邮箱 / 姓名**（可选）：填了邮箱，会在建租户的同一步顺带开通该租户的第一个管理员账号；不填则只建一个空租户，后续再手动邀请成员。

## 一次性凭据面板

如果同时填了首管邮箱，且当前部署的成员开通方式是「初始密码」模式（而非发邮件模式），创建成功后界面会弹出**一次性凭据面板**：登录地址 / 账号 / 临时密码。

这个面板**只在这一次展示**——关闭之后无法再从界面找回同一个密码。复制内容交给该租户的首管即可；密码只应通过你和对方之间可控的渠道传递，不要留存到聊天记录、工单、截图等无法控制访问范围的地方。

如果面板关早了或密码丢了，不需要重新建租户：切到该租户后在「成员」管理页对该账号做「重置密码」，会重新生成一个临时密码。

（如果部署走的是发邮件模式，创建成功后不会弹这个面板——首管会收到一封设置密码的邮件，走首篇《平台概览与登录》里说的自助设置密码流程。）

## 租户配额入口

要给某个租户设置用量上限，先切入该租户（在租户列表点「管理」，或用顶栏的租户切换器选中它），再在左侧「设置」分组打开「租户配额」页（`/settings/tenant-quotas`）。可配置的维度包括 `qps`、`tokens_per_day`、`sandboxes`、`monthly_token_budget`、`image_upload_count_30d`、`image_storage_bytes`、`artifact_download_count_30d`、`workspace_bytes_per_user`。

其中 `workspace_bytes_per_user` 是**按成员维度**的工作区容量上限——限制的是租户下单个成员能占用的工作区字节数，不是整个租户的总量；和 `image_storage_bytes` 一样以字节为单位，页面上会附带 GiB/MiB 的换算提示，方便按人肉可读的容量去设置。没有为某个维度建记录，等于该维度不设上限。

## 停用语义

租户列表页每行都有「停用」操作，点击后需要二次确认。停用**不会删除任何数据**——只是把租户状态从「正常」切到「已停用」：一旦停用，该租户下所有成员后续的请求都会被直接拦下，直到管理员在同一页点「恢复」把状态切回「正常」。停用前建议先和租户方对齐，避免影响其正在进行的工作。
