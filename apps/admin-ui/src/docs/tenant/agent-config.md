## 去哪找

左侧菜单「智能体」，点某一个 Agent 的名字进入它的详情页。

## 详情页的标签页

顶部有一排标签：概览 / 配置清单 / 配置历史 / 调试台 / 用户 / 对话 / 技能 / 触发器。改配置在「配置清单」标签页里；「调试台」是拿这个 Agent 试跑对话用的（见另一篇《会话与调试台》）；「配置历史」能看每次保存留下的修订记录，支持两两对比和回滚。

## 配置清单的结构

「配置清单」标签页左侧是一列分组导航，一共 10 组：

- 基础
- 模型与路由
- 提示词与输出
- 能力
- 记忆
- 运行预算与超时
- 上下文与压缩
- 安全与防护
- 沙箱与资源
- 触发器与可观测

点哪组，右边就显示哪组的字段；右上角有个「搜索设置…」输入框，敲关键字（中英文都行）能直接跳转到相关的组。

其中两个组内部还分了二级标签页：

- **能力**组下面是 工具 / MCP / 知识库 / 技能 / 子 Agent 五个子标签。
- **安全与防护**组下面是 防护开关 / 人工审批 / 子任务与网络 三个子标签（提示注入防护、输出审查/判分/脱敏、动作前置审查等开关都在「防护开关」子标签里）。

右上角还有一个「YAML」按钮，点了会切到原始 YAML 编辑（面向熟悉配置格式的用户的逃生舱）；如果当前 YAML 不合法，切不回表单视图会有提示。

## 三档预设（运行策略）

「基础」组最上方有一张「运行策略」卡片，一键套用三档常用组合（涉及记忆、步数、压缩等十几个分散字段）：

- **均衡推荐**（默认）：日常够用，费用适中。
- **成本优先**：省 token——少记少想、更早压缩，长对话更省钱。
- **能力优先**：多记多想——步数翻倍、记忆更全，复杂任务更稳，费用也更高。

选一档后，如果会真的改动当前配置，会先弹一个确认框告诉你将调整几项设置，确认后才写入；写入之后，每一项仍然可以在各自的分组里单独微调。手动调过某一项之后，卡片会显示一个「自定义」标签，并提示当前离哪个预设最近、还差几项。

## 保存与重置

右上角「重置」按钮把编辑区还原为服务器上当前保存的版本（不影响已经保存过的内容）；「保存」把改动提交上去，后端会重新校验整份配置，格式不对会报错并显示原因。

## 启用 / 禁用

详情页标题栏右侧有一个「禁用」按钮——这是这个 Agent（所有版本）的总开关。点击需要二次确认，可以选填一个原因（会记入审计）；确认后会立即拒绝该 Agent 的新运行/新会话，并终止当前正在跑的 run。禁用后按钮变成「启用」，点一下立即恢复。

## 跨租户切入态是只读的

如果你是从平台管理员视角切换进了某个具体租户，配置清单的「保存」和启用/禁用按钮都会置灰——先退出切入态或直接以该租户身份操作。
