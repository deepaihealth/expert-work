## 是什么

服务账号（Service Account）是一个非人类身份——代表一个 bot、一条工作流或一个外部集成。API 密钥挂在服务账号名下，用来代表它调用平台的公开 API。两者是两个页面：先建身份，再发密钥。

## 第一步：建服务账号

左侧「设置」分组下点「服务账号」（`/settings/service-accounts`）。点右上角「新建服务账号」，填名称（如 `sa_data_pipeline`）和可选的描述，提交。这一步只创建身份本身，还没有能用来调用 API 的密钥。

## 第二步：发一把 API 密钥

左侧「设置」分组下点「API 密钥」（`/settings/api-keys`）。点「创建 API 密钥」，选一个服务账号，勾选它的访问范围（scope，可多选），可以选填一个过期时间（留空 = 永不过期；对外分发的密钥建议设个有效期）。

三档 scope 的含义：

- **read**（只读）：查询会话、运行结果、Agent 列表等 GET 接口。
- **write**（业务写）：在 read 的只读能力之上，可调用 Agent 运行、创建/继续会话、上传文件。
- **admin**（管理，界面上标红「危险」）：服务账号与密钥管理、授权变更——不要把带这个 scope 的密钥发给第三方。

## 一次性展示 + 之后怎么回显

密钥创建成功后会弹一个对话框，明文只显示这一次——请当场复制保存，关闭对话框后无法再看到同一段原始文本。列表里每一行平时只显示密钥前缀（例如 `aforge_pat_a1b2c_...`）；如果之后还要看完整密钥，点该行的「查看」按钮就能再次取回明文（早于「回显」功能上线时创建的老密钥例外，需要先轮换一次才能查看）。

## 轮换 / 吊销

- **轮换**：生成一把新密钥，旧密钥进入 5 分钟的宽限窗口——这段时间内旧密钥仍然可用，方便你把调用方无缝切到新密钥；新密钥同样只在此刻明文展示一次。
- **撤销**：立即让密钥失效，需要二次确认，不可逆。

## 按状态过滤

「状态」列的表头有一个筛选器（生效中 / 轮换宽限 / 已撤销 / 已过期），点表头的筛选图标勾选状态即可缩小列表范围。
