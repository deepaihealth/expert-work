## 发起一次会话

左侧「智能体」点进你要测试的那个 Agent，切到「调试台」标签页。第一次进入点「新建会话」建一个新的对话线程；下方输入框写提示词，点「运行」发出去。同一个会话可以连续对话多轮，历史都留在下面的对话记录里；也可以随时点「继续会话…」回到之前建过的某个线程接着聊。

输入框旁边还有「添加图片」「添加文档」两个附件入口，支持带图/带文件跑一次。

## 看运行时间线和工具调用

每一轮回复下方可以展开事件时间线，按发生顺序显示这一步是什么类型：`agent`（模型思考+调工具/给回复）、`memory_recall` / 写回记忆、`planner`（规划）、`reflect`（接受/修订）、压缩/重试/出错标记，以及等待人工审批的 `approval` 步骤。点开某一步能看到它的输入输出、思考过程原文。每一轮卡片顶部会汇总这一轮调用了几个工具、有没有失败，以及输入/输出/缓存/思考 token 用量和耗时。

## 审批

如果这个 Agent 给某些工具配置了「人工审批」（配置清单「安全与防护」组下的「人工审批」子标签），运行到那一步会暂停，界面上出现「待审批」标签，可以直接在调试台里点「批准」或「拒绝」继续（如果还要顺手改一下参数再批准，需要去对应的运行详情页）。

不在调试台里也能处理——左侧「审批」是一个独立的全租户审批队列（`/approvals`），把所有等待你处理的审批项集中在一张表里，支持批量批准/拒绝、按状态筛选、一键批准本页全部，并且会显示每一项已经等了多久、还有多久超时。

## 回看历史会话

左侧「对话」（`/conversations`）是一个跨 Agent 的会话浏览器，可以按状态（进行中 / 已暂停 / 已完成 / 失败 / 已取消 / 已归档）、Agent、用户等条件过滤。点进某一条会话，能看到只读的历史轮次重建——外观和调试台一致，但不能再往里发新消息。
