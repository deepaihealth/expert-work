## 这是什么

Expert Work 是一个多租户的 AI Agent 平台：你所在的团队（租户）下，每个用户都拥有一个专属的、持久化的智能体实例——独立的对话历史、长期记忆和工作空间，而不是一个用完即走的聊天窗口。登录后你可以在这里和你的 Agent 对话、查看历史记录，管理员还能管理团队成员、配置 Agent。

## 登录入口

打开管理后台地址会先进入登录页。如果你的团队接入了统一身份认证（SSO），点「使用 SSO 登录」，跳转到身份提供方完成登录后会自动回到平台。

你的账号由所在租户的管理员创建或邀请——如果还没有账号，请联系你的管理员开通。管理员开通账号通常是两种方式之一：

- 发一封「设置密码」的邮件给你，你点邮件里的链接自己设置密码；
- 直接告诉你一个初始密码，登录时会要求你立即修改（见下一节）。

## 首次登录会要求你改密

如果你拿到的是管理员给的**初始密码**，这个密码只是**临时**的。用它登录时，系统会强制弹出「修改密码」页面，要求你先设置一个只有自己知道的新密码，才能继续使用——这是正常流程，不代表账号有问题。

设置成功后，之后用新密码正常登录即可，不会再要求修改。

## 忘记密码怎么办

平台目前没有自助的「忘记密码」入口。如果你忘记了密码，请联系你所在租户的管理员——管理员可以在成员管理页为你重置密码。重置后你会拿到一个新的临时密码，登录时同样会被要求立即修改，按上一节的流程操作即可。
