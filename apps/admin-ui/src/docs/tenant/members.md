## 这是什么

「成员」页面管理你所在租户的员工账号——邀请新人、分配角色、重置密码、停用或移除。左侧菜单「设置」分组下点「成员」（路径 `/settings/members`）进入。

## 邀请新成员

点右上角「邀请」按钮，打开邀请抽屉：填邮箱、选角色（下拉框里是 `admin` / `operator` / `viewer` 三个原始值，默认 `viewer`），显示名称可选填，点「发送邀请」。

平台的账号开通方式由部署配置决定，同一个环境下只会是下面两种之一：

- **邮件模式**：系统发一封「设置密码」邮件给对方，对方点邮件里的链接自己设置密码。界面上只会提示「邀请已发送」。
- **密码模式**：界面直接弹出一个「一次性凭据」面板，显示登录地址 / 账号 / 初始密码，并带「复制全部」按钮。**这段密码只显示这一次**，关闭面板后无法再次找回原文——务必当场复制转告员工，再点「我已保存，关闭」。

批量邀请一次最多 50 个，某一个邮箱冲突（比如已存在）不会拖累其他邮箱，失败的会单独提示。

## 角色含义

角色是 `admin` / `operator` / `viewer` 三档（以平台权限矩阵为准），按"资源类别"精确划分，不是笼统的"权限高低"：

- **admin**：租户内的全权限——配置清单读写删、会话读写删、审计只读、租户配置读写、自己及他人记忆管理等都覆盖到。**成员、服务账号、API 密钥、角色绑定这四类只有 admin 能碰**——增删改查全部专属于 admin。
- **operator**：配置清单和会话可读写（无删除），审计只读，自己的记忆可读写删，MCP 授权可自主管理。日常跑 Agent、用调试台够用。但**成员 / 服务账号 / API 密钥 / 角色绑定这四个页面对 operator 完全不可见，包括只读**——接口层面直接拒绝，不是界面把按钮变灰。
- **viewer**：上面 operator 能碰的那些资源（配置清单/会话/审计/记忆等）全部只读；同样看不到成员/服务账号/API 密钥/角色绑定——和 operator 一样完全没有权限，连查看都不行。

## 重发邀请

状态为「已邀请」（尚未激活）的成员行会出现「重发」按钮，重新触发一次开通流程。密码模式下会弹出一个显示新一次性密码的对话框（标题「重置密码」）；邮件模式下提示「邀请已重发」，对方会再收到一封邮件。

## 重置密码

已经在系统里建好账号的成员（状态「已激活」或「已邀请」且已建号）行上有「设置密码」按钮：输入一个至少 8 位的新临时密码，点「设置」提交。该成员下次登录会被强制要求修改这个临时密码。

## 停用 / 移除

同一个「移除」按钮，效果取决于成员当前状态：

- **已邀请** → 点「移除」= 撤销邀请，邀请链接立即失效。
- **已激活** → 点「移除」= 暂停该成员，立即失去访问权限；之后可以重新邀请回来。

行尾还有一个更重的「停用并清除」按钮（危险操作，需要输入该成员邮箱确认）：不可逆地停用账号、删除其登录账号、移除角色授权，并清除其业务数据。这是员工离职时才用的一次性操作，请谨慎点击。

## 按状态筛选

页面顶部的分段控件可以按状态筛选：全部 / 已邀请 / 已激活 / 已暂停 / 已撤销。

## 跨租户视图是只读的

如果你（作为平台管理员）当前停在「全部租户」的聚合视图，这个页面只能看、不能改——邀请 / 重发 / 设置密码 / 移除都需要先切换到某个具体租户才能操作。
